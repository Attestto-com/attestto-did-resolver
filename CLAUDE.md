# attestto-did-resolver

**Read [`project-context.md`](./project-context.md) before changing anything in this repo.**

It carries the operating rules, and Rule 0 first: the published `did:sns` / `did:pki`
method specifications are the authority — not tickets, not Confluence, not memory,
not that file itself.

This file is deliberately a pointer and not a copy. Two copies of the rules would
drift, which is the defect class this repo is currently recovering from.
